# Структура отчёта по заданию № 1

1. Описание наборов данных.
2. Признаки, использованные для анализа.
3. Параметры архитектур и обучения нейронных сетей.
4. Графики обучения для архитектур с лучшими показателями качества.
5. ROC-кривые по классам для лучших классификаторов.
6. Метрики качества моделей на тестовых выборках в виде таблиц или диаграмм.
7. Программный код.

В отчёт также включить выводы по результатам построения моделей.
